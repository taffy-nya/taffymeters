# Measurement audio

`关注塔菲谢谢喵-永雏塔菲.m4a` is a 40 s excerpt (2:10–2:50, the original AAC stream, not re-encoded, metadata stripped) of 关注塔菲谢谢喵 by 永雏塔菲.

- Source and terms: <https://www.bilibili.com/opus/549924125070610709>. The author allows free non-profit use; the file name is the attribution the author asks for.
- It is not covered by the project's GPL-3.0 license and is not part of release packages. Anyone reusing it outside this project needs the author's terms, not this repository's license.

`tools/perf/run.py` decodes it with `ffmpeg` (on PATH) for the scenarios whose `stimulus` is `music`.
