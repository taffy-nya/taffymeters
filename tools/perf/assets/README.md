# Measurement audio

`关注塔菲谢谢喵-永雏塔菲.m4a` is a 40 s excerpt (2:10–2:50, original AAC stream, not re-encoded) of 关注塔菲谢谢喵 by 永雏塔菲. The file name is the attribution the author asks for; the author allows free non-commercial use. It is not covered by the project's GPL-3.0 license, and it is not part of release packages.

`tools/perf/run.py` decodes it with `ffmpeg` (on PATH) for the scenarios whose `stimulus` is `music`.
